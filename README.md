# Remont Manager

Вебзастосунок для керування ремонтними проєктами та задачами.

## Можливості

- створення, перегляд, редагування та видалення проєктів;
- керування задачами проєкту: назва, опис, пріоритет, дедлайн і статус виконання;
- автоматичний прогрес проєкту на основі виконаних задач;
- перевірка введених даних і зрозумілі повідомлення про помилки.

## Вимоги

- Python 3.11 або новіший;
- [uv](https://docs.astral.sh/uv/).

## Запуск у Windows PowerShell

У кореневій папці проєкту виконайте:

```powershell
uv sync
uv run uvicorn app.main:app --reload
```

Відкрийте <http://127.0.0.1:8000>. Інтерактивна документація API доступна за адресою <http://127.0.0.1:8000/docs>.

Під час першого запуску таблиці SQLite створюються автоматично. Дані зберігаються у файлі `task_manager.db` у кореневій папці; не видаляйте його, якщо хочете зберегти свої проєкти.
