# Roadmap: Remont Manager

Порядок виконання ітерацій. Не починай ітерацію N+1, поки не закрита ітерація N.

- [X] 001 - Модель Project та налаштування бази даних
- [X] 002 - Модель Task та зв’язок Project → Task
- [X] 003 - Головна сторінка зі списком проєктів
- [X] 004 - Сторінка проєкту та список його задач
- [X] 005 - Створення проєкту
- [X] 006 - Редагування та видалення проєкту
- [X] 007 - Створення задачі
- [X] 008 - Редагування, завершення та видалення задачі
- [X] 009 - Прогрес виконання та статистика проєкту
- [X] 010 - Валідація даних та обробка помилок
- [X] 011 - Фінальне доопрацювання інтерфейсу та адаптивність
- [ ] 012 - Фінальна інтеграція та очищення коду

## 001 - Project model and database

Створити SQLAlchemy модель Project та таблицю projects.
Додати базові поля Project.
Підготувати підключення до бази даних.
Створити початкові 4 Projects.

Результат: Project зберігається та читається з БД.

## 002 - Task model and Project → Task relationship

Створити SQLAlchemy модель Task та таблицю tasks.
Додати foreign key project_id.
Налаштувати relationship Project → Tasks.
Створити початкові Tasks для 4 Projects.

Результат: кожна Task належить конкретному Project.

## 003 - Projects Dashboard

Створити Dashboard.
Показати картки всіх Projects.
Кожна картка містить назву, Tasks, progress та посилання на конкретний Project.

Результат: користувач бачить всі Projects на одному екрані.

## 004 - Project Details and Task List

Створити сторінку конкретного Project.
Показувати тільки Tasks цього Project.
Додати навігацію назад до Dashboard.

Результат: клік по Project відкриває його Tasks.

## 005 - Create Project

Додати форму створення Project.
Поля: name, description.
Після створення повернути користувача на Dashboard.

Результат: користувач може створити новий Project через UI.

## 006 - Edit and Delete Project

Додати редагування Project.
Додати видалення Project з підтвердженням.
Визначити поведінку Tasks при видаленні Project.

Результат: Project можна повністю керувати через UI.

## 007 - Create Task

На сторінці Project додати «+ Додати Task».
Форма створює Task саме для поточного Project.
project_id не вводиться користувачем вручну.

Результат: Task автоматично прив'язується до відкритого Project.

## 008 - Edit, Complete and Delete Task

Додати редагування Task.
Додати checkbox completed.
Додати видалення Task з підтвердженням.

Результат: користувач повністю керує Tasks.

## 009 - Progress and project statistics

Розраховувати загальну кількість Tasks.
Розраховувати кількість виконаних Tasks.
Показувати progress bar та відсоток виконання.

Результат: прогрес Project формується автоматично з його Tasks.

## 010 - Validation and error handling

Додати перевірку порожніх назв.
Обробити Project/Task not found.
Обробити некоректні запити.
Додати зрозумілі повідомлення користувачу.

Результат: застосунок коректно поводиться при помилках.

## 011 - UI polish and responsive layout

Довести дизайн до узгодженого стилю.
Перевірити hover/focus/active стани.
Перевірити mobile/tablet/desktop.
Зробити кнопки та форми зручними.

Результат: цілісний та адаптивний інтерфейс.

## 012 - Final integration and cleanup

Перевірити всі основні сценарії.
Перевірити навігацію.
Перевірити CRUD Project.
Перевірити CRUD Task.
Перевірити Project → Task relationship.
Очистити дубльований або непотрібний код.
Оновити README.

Результат: готовий навчальний проєкт Remont Manager.
