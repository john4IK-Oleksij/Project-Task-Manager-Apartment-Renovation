# Місія проєкту: Remont Manager

## Що ми будуємо

Вебзастосунок для керування ремонтом квартири.

Основна модель має два рівні:

Project
→ Task

Один Project має багато Tasks. Кожна Task належить одному Project через project_id.

## Початкові Projects

1. Ремонт кухні
2. Ремонт ванної
3. Заміна всіх дверей і вікон
4. Косметичний ремонт решти приміщень

Кожен Project має приблизно 4–5 реальних Tasks.

## Основні можливості

Користувач може:
- переглядати всі Projects;
- відкривати конкретний Project;
- бачити Tasks цього Project;
- створювати, редагувати та видаляти Projects;
- створювати, редагувати та видаляти Tasks;
- змінювати статус Task на виконано/не виконано;
- бачити прогрес виконання Project.

## Моделі

Project:
- id
- name
- description
- created_at

Task:
- id
- title
- description
- completed
- project_id
- created_at

Зв'язок:

Project 1 → багато Tasks
Task → один Project

## UI

Основний екран — Projects Dashboard.

Він містить:
- заголовок «Ремонт квартири»;
- кнопку «+ Додати Project»;
- картки Projects;
- Tasks у кожній картці;
- кількість виконаних Tasks;
- progress bar;
- кнопку/посилання «Відкрити Project →».

Картка Project клікабельна та веде на сторінку конкретного Project.

Сторінка Project містить:
- назву;
- опис;
- progress;
- список Tasks;
- «+ Додати Task»;
- редагування та видалення.
